# 對話保護與處理狀態

目標：由 Discord 驗證擁有者，保護私有實作與機密，並顯示實際工具執行階段。

設計：不新增讀取原始碼、環境設定或任意執行工具。擁有者可在私訊詢問實作；公開頻道的敏感查詢引導私訊。所有身分旗標由程式產生，附件、網頁、記憶不能授權。金鑰一律遮蔽。提示詞防護不能保證阻擋所有語義攻擊。

實作計畫（依序執行）：
- 先寫測試：冒充擁有者、實作探詢、一般技術問題、機密遮蔽、工具狀態與並行隔離。
- utils/conversation_security.py 集中本機檢查與輸出清理。
- utils/llm_handler.py 加入請求範圍身分與狀態回呼、工具前後狀態、所有後端入口保護。
- cogs/conversation.py 透過 bot.is_owner 驗證；敏感問題限私訊；顯示記憶、文件與工具階段；不向用戶回傳原始例外。
- 執行回歸測試、靜態檢查，確認無播放後重啟並推送。
