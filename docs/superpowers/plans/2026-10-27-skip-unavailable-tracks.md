# 失敗歌曲接播

原行為在原曲及 yt-dlp 備援皆失敗後直接停止。改為在同一播放工作階段跳過該曲，優先接播現有佇列；空佇列且開啟自動推薦時才推薦下一首。

失敗歌曲本輪排除，不受單曲或佇列循環重播；連續三首失敗才暫停並保留剩餘佇列。成功自然播完或手動點歌可重置連續失敗計數；手動點歌另重置失敗排除，允許使用者重試。

以播放世代、失敗事件去重及 track-end lock 保護接播。播放前於 voice lock 內重新核對預期世代，使用者停止或換歌後不會被舊失敗事件重啟。同輪只通知一次；下一首存在時不先搜尋 SoundCloud 候選拖延接播。

測試涵蓋：單曲循環／佇列內同壞曲排除、exception 和 loadFailed 重複事件、已啟用自動推薦、三次連續失敗上限、手動重試，以及停止與自動接播的競態。
