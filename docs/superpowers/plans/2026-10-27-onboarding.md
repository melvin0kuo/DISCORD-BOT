# 新手部署體驗

目標：Windows 雙擊啟動本機網頁，逐步建立 Python 環境、設定帳號與模型、安裝音樂服務、檢查連線並啟動。

採用 Python 標準函式庫提供 loopback 網頁，不需先安裝網頁框架。可選 Gemini（不需要 GPU）或 LM Studio；模型下載及第三方登入在官方工具／網站進行。不宣稱能自動完成帳號申請、條款或任何硬體的本機模型安裝。

- 先寫失敗測試：設定保留與遮蔽、參數驗證、請求驗證、工作狀態與固定動作。
- 實作 setup_wizard.py 與獨立 setup_ui/，僅監聽 127.0.0.1；隨機 session、Origin 檢查，金鑰不回傳前端。
- 新增 Windows 啟動腳本（Python 3.11／3.12，缺少時引導 winget 安裝），建立獨立 .bot-venv、不碰既有環境。
- 沿用既有音樂安裝程式；新增相容的最小執行需求檔，避免新手安裝未使用的本地訓練套件。
- 重寫 README；原詳細功能移至 docs/features.md，補上首次設定、疑難排解、資料與金鑰處理說明。
- 測試 HTTP 介面與隔離環境安裝；瀏覽器驗證版面與互動，最後審查、提交、推送。
