# 功能完善與驗證計畫

目標：保留既有資料與部署方式，修復已檢視的七項功能缺口。

1. 音樂控制：所有會改動播放的按鈕、選單和表單，驗證操作者所在語音頻道及播放器是否仍有效；唯讀分頁維持開放。
2. 正式運行：預設關閉熱重載，本機設定同步關閉，避免修改檔案造成播放重載。
3. 長文件：提高可擷取資料範圍，分段摘要後合併；掃描 PDF 使用本機視覺模型讀圖，超出處理範圍明確告知。
4. 網路搜尋：搜尋結果之外的連結與無資料支持的完整地址不得直接當作查證結果。
5. 本地記憶：使用本機 Nomic embedding，分開保存舊向量索引；記錄失敗而不阻止聊天。
6. 長回覆：使用模型 tokenizer 計算輸入，預留回答空間，必要時摘要舊對話；不可裁掉本輪問題。
7. 訊息傳送：分頁編輯失敗時改送完整頁面，避免靜默遺失文字。

每項先建立會失敗的回歸測試，再實作與驗證。整合後執行完整測試、程式碼檢查、本機模型測試與程式碼審查；確認無播放中的歌曲後重啟並推送來源檔。
